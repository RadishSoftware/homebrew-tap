# Homebrew tap for Mobster

```sh
brew install radishsoftware/tap/mobster
```

`mobster` is [Mobster CLI](https://github.com/RadishSoftware/mobster-cli): the command line, MCP server and agent loop that let any agent use a real iPhone over USB, or an iOS simulator, from an Apple silicon Mac. The cask in `Casks/` installs the release build from the project's GitHub releases, so Homebrew compiles nothing.

The cask is updated with each release. Docs are at [docs.mobster.dev](https://docs.mobster.dev). Report problems in the [main repository](https://github.com/RadishSoftware/mobster-cli/issues), not here.
