# Homebrew tap for Mobster

Mobster is coming soon: [mobster.dev](https://mobster.dev). Until it ships, the casks here install nothing: `brew install --cask radishsoftware/tap/mobster-app` stops with "has been disabled because it is coming soon: mobster.dev".

`mobster-app` is [Mobster for Mac](https://mobster.dev): it lets AI use a real iPhone over USB, or an iOS simulator, from an Apple silicon Mac. The app updates itself. Your coding agent gets Mobster's MCP server from the app: Settings › Connectors › Use Mobster from… › **Add**.

The `mobster` cask is the Mobster CLI 0.3.0, now part of Mobster for Mac. A `mobster` you installed with it keeps working.

Follow [@getmobster](https://x.com/getmobster) for the launch. Docs are at [docs.mobster.dev](https://docs.mobster.dev). Get help at [mobster.dev/support](https://mobster.dev/support).
